A clone of the example Patchbox OS module to try to run PiPedal which probably
needs more attention because the \*.deb installer seems to be doing a lot of
work already done on patchboxOS

Place it in /usr/local/patchbox-modules/imported/

Or run*:

```
patchbox module install https://github.com/jkirchartz/Patchbox-PiPedal
```
